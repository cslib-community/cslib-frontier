# cslib-frontier

We’re building a library of computer science results, from algorithms to cryptography. We write
proofs in Lean, a language that lets a computer check each step. Our work builds on
[CSLib](https://github.com/leanprover/cslib).

## Explore a proof

An employee table has four rows and a department table has three. How can joining them on
department ID give six? Follow the matches by hand, then see how Lean checks the counting rule.
[Read the SQL walkthrough](https://www.cslib.io/cslib-frontier/guide/SQL-Query-Semantics/)
or [browse the guide](https://www.cslib.io/cslib-frontier/guide/).

## Get involved

**Share an idea.** What result do you wish you could look up here? Describe it in your own
words. A textbook page, a paper, or a small example can help someone else write the Lean proof.
[Suggest an idea](https://github.com/cslib-community/cslib-frontier/issues/new?body=I%27d+like+to+see+...%0A%0AA+source+or+example+is+...).

**Bring an AI coding agent.** Pick an open issue that interests you. Try asking your agent,
“What’s already proved here? Show me a small example we could add.” Compare its statement
with the source, check it in Lean, and say how the agent helped when you share it for review.
[Browse open issues](https://github.com/cslib-community/cslib-frontier/issues) ·
[Contributing with AI](CONTRIBUTING.md#ai-assistance-and-review).

For setup instructions and the library index, see the [manual](manual/README.md).
